# Phase 23 — Vie scolaire

Statut : **Terminé** — 2026-10-03.

Le module couvre les incidents, niveaux de gravité, mesures disciplinaires et clôture des dossiers. L’infirmerie conserve les symptômes, la prise en charge, le suivi et l’information du responsable.

Les permissions de santé sont distinctes de celles de discipline afin de protéger les données confidentielles.
